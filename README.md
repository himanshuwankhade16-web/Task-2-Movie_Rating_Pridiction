# Movie Rating Prediction

## CodSoft Data Science Internship - Task 2

### Project Overview

The Movie Rating Prediction project aims to predict movie ratings based on various features such as genre, director, actors, votes, and year of release using Machine Learning techniques.

The objective is to build a predictive model that can estimate a movie's rating and analyze the factors that influence movie success.

---

## Dataset Information

The dataset contains information about movies, including:

* Movie Name
* Year of Release
* Duration
* Genre
* Director
* Actors
* Votes
* Rating
